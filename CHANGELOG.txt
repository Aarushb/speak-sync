SpeakSync Changelog

To jump between versions using Find (Ctrl+F), search for:
  # for major versions (e.g. # 1.0.0)
  ## for minor versions (e.g. ## 0.2.0)
  ### for revision and patch updates (e.g. ### 0.1.2)

### 0.1.2 (2026-11-26)
- Automatic background update checks:
  SpeakSync now checks for new releases periodically in the background without
  interrupting your workflow.
- System tray update notifications:
  When an update is found, SpeakSync alerts you non-intrusively via a toast
  notification and adds an "Update Available" item directly in your system tray
  menu.
- In-app changelog review and installation:
  Selecting the update item shows you exactly what changed in the new version,
  downloads the update with an accessible progress indicator, and automatically
  installs and restarts the application.
- Safe update fallback:
  If a download or installation cannot complete automatically, a clear error is
  displayed with a direct link to open the download page in your browser.
- Search-friendly changelog:
  Changelog entries now use standard search identifiers without clutter or
  repetitive divider lines.

### 0.1.1 (2026-11-26)
- Faster status updates:
  Sync changes are now detected twice as fast, catching even brief file uploads.
- Smaller download size:
  Sound cues now take up significantly less space with no loss in audio quality.
- Screen reader reconnect:
  If you restart NVDA, JAWS, or your screen reader, SpeakSync automatically
  reconnects speech output without needing an app restart.
- Portable version improvements:
  The Windows portable version starts faster and runs more smoothly.
- Settings guidance:
  Added clear explanations in the settings window to help you adjust update
  speed and performance.
- Release changelog:
  Added this changelog file to all download packages so you can easily review
  what is new.

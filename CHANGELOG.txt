SpeakSync Changelog
================================================================================

Version 0.1.1 (2026-11-26)
--------------------------------------------------------------------------------
- Faster status updates:
  Sync changes are now detected twice as fast, catching even brief file uploads.
- Smaller download size:
  Sound cues now take up significantly less space with no loss in audio quality.
- Screen reader reconnect:
  If you restart NVDA, JAWS, or your screen reader, SpeakSync automatically
  reconnects speech output without needing an app restart.
- Portable version improvements:
  The Windows portable version starts faster and runs more smoothly.
- Settings guidance:
  Added clear explanations in the settings window to help you adjust update
  speed and performance.
- Release changelog:
  Added this changelog file to all download packages so you can easily review
  what is new.


Version 0.1.0 (2026-10-15)
--------------------------------------------------------------------------------
- Multi-cloud sync monitoring:
  Monitors status for Dropbox, Google Drive, OneDrive, Nextcloud, and other
  cloud storage services in the background.
- Screen reader accessibility:
  Fully accessible with NVDA, JAWS, VoiceOver, Orca, and Windows speech.
  Every button, status message, and dialog is labeled and keyboard accessible.
- Audio cues:
  Plays optional sound cues when syncing begins, while in progress, and when
  completed.
- Global keyboard shortcuts:
  Press shortcuts anywhere to hear current sync status or open the settings.
  Press a slot shortcut twice to copy the status directly to your clipboard.
- Portable and installer packages:
  Available as both a portable zero-install package and a standard installer
  for Windows, Mac, and Linux.

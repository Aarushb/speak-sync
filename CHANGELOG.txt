SpeakSync Changelog
================================================================================

Version 0.1.1 (2026-11-26)
--------------------------------------------------------------------------------
New Features & Enhancements:
* Faster Sync Detection:
  - Reduced default background tray polling interval from 1.5s to 0.75s (750ms).
  - Sync events for small or rapid file modifications are now caught reliably
    with minimal latency (~21ms query duration, ~2.8% CPU footprint).
* Polling Interval Help & Guidance:
  - Added an accessible explanation label and tooltip in the Manage Sources &
    Settings dialog (General Settings) explaining the trade-offs of lower vs.
    higher polling intervals.
* Lightweight OGG Vorbis Audio Earcons:
  - Added compressed .ogg earcons (start.ogg, loopty.ogg, finish.ogg), cutting
    the bundled audio asset size by 60% (from ~180 KB to ~69 KB).
  - Audio resolver now seamlessly supports .ogg, .flac, and .wav formats with
    automatic fallback.
* Screen Reader Auto-Reconnection:
  - SpeechService now automatically detects screen reader disconnects or
    restarts (e.g. restarting NVDA) and seamlessly re-initializes connection
    on the next announcement.
* Windows UIA Stability for Portable Mode:
  - Pre-compiled and bundled UIAutomationCore typelib (comtypes.gen) directly
    into PyInstaller packaging so portable builds never need to compile COM
    interfaces on the fly at runtime.
* Comprehensive Changelog Bundled:
  - CHANGELOG.txt is now included in all release archives (Windows portable zip
    and installer, macOS DMG and zip, Linux DEB and tarball).

Version 0.1.0 (2026-10-15)
--------------------------------------------------------------------------------
Initial Release:
* Multi-Source Cloud Sync Monitoring:
  - Support for Dropbox, Google Drive, Microsoft OneDrive, Nextcloud, Resilio,
    Mega, iCloud, and custom user-defined tray rules.
  - Automatic detection of both visible tray icons and hidden overflow icons
    across Windows 10, Windows 11 (XAML NotifyItemIcon), macOS, and Linux.
* Screen Reader Accessibility:
  - Direct speech and refreshable braille output via Prism (NVDA, JAWS,
    VoiceOver, Orca, SAPI5/OneCore fallback).
  - Dedicated accessible dialogs with standard tab navigation, screen reader
    labels, and hotkeys.
* 3-Stage Audio Cues (Earcons):
  - Spatial audio feedback for sync transitions: start earcon, sustained loop
    sound while syncing, and completion finish earcon.
* Global Hotkeys:
  - Slots 1-9 status queries, summary query (Alt+Shift+0), and Manage Sources
    dialog (Alt+Shift+M). Pressing a slot hotkey twice quickly copies the
    status text directly to the clipboard.
* macOS Status Menus Bar:
  - Native integration with the macOS top-right Status Menus bar (accessible
    via VO+M twice) with full VoiceOver label support.
* Cross-Platform Packaging:
  - Standalone portable ZIPs and native installers for Windows, macOS, and Linux.
